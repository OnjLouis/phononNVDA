Phonon for NVDA

Offline speech using Gradium's multilingual Phonon engine. Includes 102 voices for English, French, German, Spanish and Portuguese. The model and voices are included, with no first-use download required.

Requirements and Setup

Requires 64-bit NVDA 2026.2 or later, Windows 10 or later and an AVX2-capable processor. Older processors and 32-bit NVDA cannot load this runtime.

Install the add-on and restart NVDA. Open the synthesizer selection dialog with NVDA+Control+S and choose Phonon. The model and voices are included in the package.

Alternative: Ollama Speech.

Speech Controls

Choose Language filter and Voice in Speech settings or the synth settings ring. English Character Voices groups the catalogue's character voices separately from British and American English. The filter limits the voice list; it does not translate text. The model supports the five languages listed above.

To add a voice exported from Gradium Studio, open NVDA Settings, Phonon, then Manage imported voices. Choose Add voice, select the .safetensors file, and use Preview voice before saving it. Preview uses English until you choose a language. Select its spoken language and enter a name to import. To correct the language later, select the import and choose Change language. This keeps the same voice and settings. You can then select it like a built-in voice. Imports stay in the NVDA profile and are not uploaded. Remove voice removes Phonon's copy, not the original.

Pause length is available in the synth settings ring and Speech settings. Default leaves Phonon's audio unchanged. Shorter trims sustained quiet gaps, and Longer adds time to sustained gaps between spoken sounds. These options do not change punctuation or explicit pauses requested by NVDA.

Voice variation is experimental and is available in Speech settings and the synth settings ring. Default keeps Phonon's usual sound. Less and More change how much the delivery varies. The difference may be subtle and depends on the voice and text. This setting does not select an emotion or change the voice.

Rate, Rate boost, Pitch and Volume use NVDA's streaming Sonic processing. Audio plays through NVDA's selected output device. Shift pauses or resumes; Control stops speech. The engine finishes its current calculation before starting replacement speech, so responsiveness depends on the processor.

If the native engine fails, the active driver switches to eSpeak NG to preserve access. Keep a familiar alternative synthesizer available.

Settings and Updates

The Phonon settings panel contains GPU acceleration, Graphics adapter, Status, Manage imported voices, Check for updates, Check for updates now and Help. Update intervals are Never, Hourly or Daily; Daily is the default. Help opens this manual.

Use GPU acceleration when available is checked by default. Phonon uses a compatible NVIDIA, AMD or Intel graphics device through its installed Vulkan driver. No CUDA toolkit is required. Performance depends on the device; disable it if CPU speech works better. After changing this option, switch to another synthesizer and back to Phonon, or restart NVDA.

Graphics adapter lists compatible GPUs reported by Vulkan. Automatic normally prefers a discrete GPU. To use a specific adapter, choose it by name, save the settings, then select Phonon again. If the selected adapter is unavailable, Phonon uses the CPU. Choose Automatic or another listed adapter to try GPU acceleration again.

Phonon tests GPU synthesis before using it. If initialization fails, it quietly uses the CPU, without a popup or spoken warning. The reason is recorded once in the NVDA log. A different adapter can still be tried in the same session. No graphics driver is downloaded or installed. CPU speech remains available without a GPU.

Status lists built-in and imported voice counts and reports the running engine, rather than just whether a GPU is present. It identifies the active Vulkan adapter by name and distinguishes CPU with GPU disabled from CPU fallback after unsuccessful GPU initialization. If Phonon is not selected, no backend is assumed. The field updates only while this settings panel is open.

Updates require a valid Phonon signature and matching package identity, version, size and hash. Downloads are staged outside the add-ons folder and installed by NVDA after your approval. Restart NVDA when prompted. Saved speech settings are kept.

Privacy

Speech is generated on this computer. Spoken text and audio are not saved or sent over the network. Only update checks and approved update downloads use the network. Automatic update checks can be disabled.
